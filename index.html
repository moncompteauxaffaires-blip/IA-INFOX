Vérification d'informations assistée par intelligence artificielle

Une information vous semble douteuse ?

Collez une affirmation, un extrait d'article ou un lien. Ce prototype simule une analyse structurée. Dans une version connectée, l'IA recherchera des sources et présentera les éléments permettant de vérifier l'affirmation.

Important : une analyse automatique n'est pas une preuve. Les résultats doivent être vérifiés à partir des sources originales, surtout pour les sujets sensibles ou d'actualité.
